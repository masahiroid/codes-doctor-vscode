# Repository instructions

- For each completed task that changes this extension, increment the package version. Use a patch increment by default unless the user requests a different version.
- Keep `package.json`, the top-level version in `package-lock.json`, and `packages[""].version` in `package-lock.json` synchronized.
- Add a matching entry to `CHANGELOG.md` describing the completed changes.
- Increment once per completed change task, not for every individual file edit or follow-up question. Do not publish a release unless requested.
