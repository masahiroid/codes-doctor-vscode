# API Reference

- English: this document
- 日本語: [API_REFERENCE.ja.md](API_REFERENCE.ja.md)

Last updated: 2026-10-09

All responses are JSON (except `GET /`, `GET /reports/:analysisId`, and `GET /reports/:analysisId/pdf`, which return HTML/PDF). Error responses follow `{ "success": false, "error": "<message>" }` unless noted otherwise.

## `GET /`

Returns the Web UI (upload form + local-path analysis form).

## `POST /api/upload`

Upload a ZIP file and run analysis on its contents.

**Query parameters**

| Name | Values | Default |
|------|--------|---------|
| `language` | `auto` \| `typescript` \| `javascript` \| `php` \| `dart` \| `python` | `auto` |

**Request**: `multipart/form-data` with a `file` field containing a `.zip` file (must have a `.zip` extension and `application/zip` MIME type). Max size is `CSAP_MAX_FILE_SIZE` (default 500MB).

**Response** `200`
```json
{
  "success": true,
  "analysisId": "a1b2c3d4-...",
  "extractedPath": "/path/to/temp/a1b2c3d4-...",
  "language": "auto"
}
```

**Errors**
- `400` — no file uploaded, or the file doesn't pass the ZIP filter
- `413` — file exceeds `CSAP_MAX_FILE_SIZE`
- `500` — ZIP extraction failed

## `POST /api/analyze-path`

Analyze a local directory the server process can read (no upload involved).

**Request body**
```json
{
  "repoPath": "/absolute/path/to/repo",
  "language": "auto"
}
```

`language` accepts the same values as above and defaults to `auto` if omitted.

**Response** `200`
```json
{
  "success": true,
  "analysisId": "a1b2c3d4-...",
  "repoPath": "/absolute/path/to/repo",
  "reportUrl": "/reports/a1b2c3d4-...",
  "reportPath": "/path/to/output/a1b2c3d4-....html"
}
```

`reportPath` is an absolute filesystem path to the generated HTML file — useful for callers (like the VS Code extension) that read the file directly instead of going through `reportUrl`.

**Errors**
- `400` — `repoPath` missing, doesn't exist, or isn't a directory
- `500` — analysis failed

## `GET /api/health`

Health check.

**Response** `200`
```json
{ "status": "ok", "timestamp": "2026-10-09T12:00:00.000Z" }
```

## `GET /reports/:analysisId`

Fetch the generated HTML report. `analysisId` must be a valid UUID (the format generated by the upload/analyze endpoints); an invalid ID returns a 400 "not found" page rather than a JSON error.

**Query parameters**

| Name | Values | Default |
|------|--------|---------|
| `language` | same as above | `auto` |

If the report hasn't been generated yet but the extracted source still exists in the temp directory, this endpoint runs the analysis on demand (useful for re-analyzing with a different `language` value) and returns the freshly generated HTML.

**Response**: `text/html`. `404` with an HTML "not found" page if neither the report nor the source exists.

## `GET /reports/:analysisId/pdf`

Render the HTML report to PDF via a headless browser (Puppeteer) and download it.

**Response**: `application/pdf`, filename `code-doctor-report-<analysisId>.pdf`.

**Errors**
- `400` — invalid `analysisId`
- `404` — report not found (generate the HTML report first via `GET /reports/:analysisId`)
- `500` — PDF rendering failed

## `POST /api/llm/analyze`

Run an LLM-based structural review. Requires `CSAP_LLM_ENABLED=true` and `OPENAI_API_KEY` to be set.

**Request body**
```json
{
  "analysisId": "a1b2c3d4-...",
  "focus": "graph-metrics",
  "useCache": true,
  "astOnlyMode": false,
  "model": "gpt-5.4",
  "maxOutputTokens": 3000,
  "temperature": 0.2
}
```

| Field | Required | Notes |
|-------|----------|-------|
| `analysisId` | yes | Must be a valid UUID from a prior analysis |
| `focus` | no | Free-text focus area; ignored when `astOnlyMode` is true (fixed to `ast-structure-only`). Defaults to `graph-metrics` |
| `useCache` | no | If true and a cached result exists for this `analysisId`+`focus`, returns it without calling the LLM |
| `astOnlyMode` | no | Switches to the AST-structure-only context/prompt instead of the metrics-driven one |
| `model` | no | Overrides `CSAP_LLM_MODEL` / `CSAP_LLM_AST_MODEL` for this request |
| `maxOutputTokens` | no | Overrides the configured max tokens (clamped to a minimum of 200) |
| `temperature` | no | Overrides the configured temperature (clamped to 0–2) |

**Response** `200`
```json
{ "success": true, "cached": false, "result": "...LLM analysis text..." }
```

**Errors**
- `400` — `analysisId` missing/invalid, LLM disabled, or `OPENAI_API_KEY` not set
- `404` — no saved analysis context for this `analysisId` (re-run the analysis first)
- `500` — the LLM request itself failed

## `GET /api/llm/result/:analysisId/:focus`

Fetch a previously saved LLM result without calling the LLM again.

**Response** `200`
```json
{ "success": true, "result": "...", "createdAt": "2026-10-09T12:00:00.000Z", "mode": "full" }
```

**Errors**
- `400` — invalid `analysisId` or `focus`
- `404` — no saved result for this combination

## Notes on `analysisId`

Every endpoint that takes an `analysisId` validates it against a UUID pattern before touching the filesystem. This exists specifically to prevent path traversal through a crafted ID — don't bypass it by constructing paths manually if you're integrating against this API.
