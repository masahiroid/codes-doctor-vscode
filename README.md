## Key Features

- **In-Editor Security & Debt Diagnostics**: See security findings with input-to-sink data-flow steps, God Classes, and technical debt scores directly in VS Code's Problems panel, hovers, and status bar.
- **Taint Data-Flow Analysis**: Distinguishes between untrusted external inputs reaching dangerous sinks (SQL injection, XSS, command execution, path traversal) and harmless constant calls to eliminate false positives.
- **1-Click AI Fix Diff Preview**: Preview proposed security and refactoring fixes in a side-by-side diff editor powered by GitHub Copilot (`vscode.lm`) or external LLMs (OpenAI, Anthropic, Gemini).
- **Fast Git-Diff Analysis**: `Analyze Git Changes` scans only uncommitted or recently modified files in seconds.
- **Complete SBOM & Vulnerability Scan**: Full software bill of materials (direct, transitive, and dev dependencies) with Trivy or `npm audit` CVE detection.
- **CI/CD Quality Gates**: Enforce minimum security and debt scores in GitHub Actions with exit codes.
- **Privacy First**: Zero network transmissions for core static analysis; code stays strictly on your local machine.

## Quick Start

### VS Code Extension

1. Install **Codes Doctor** from the [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=masahirocom.codes-doctor) (requires VS Code 1.90+).
2. Open a workspace folder.
3. Click the **Codes Doctor stethoscope icon** in the Activity Bar.
4. Click **Analyze Current Workspace** (or run `Codes Doctor: Analyze Current Workspace` from the Command Palette).
5. Review the generated HTML report, and click on any diagnostic in the **Problems** panel to jump to source code.

### CLI (Terminal & CI)

Run instant analysis without global installation:

```bash
# Run analysis and output report
npx @codes-doctor/cli analyze . --out ./reports

# CI Quality Gate: fail if security score is below 80
npx @codes-doctor/cli analyze . --min-security 80 --min-debt 75
```

## Development

Requires Node.js 24 or newer (`.nvmrc`).

```bash
npm run install:all   # Run npm ci in every package
npm run verify:deps   # Verify lockfile matches, registry signatures, and OSV advisories
npm test              # Run engine build, CLI tests, and extension tests (100+ tests)
npm run package:vsix  # Clean build and package the VS Code extension VSIX
```

### Dependency & Security Policies

- Install scripts run only when explicitly allowed in `allowScripts` within each package's `package.json`.
- Known vulnerabilities (npm advisories or OSV) fail CI automatically.
- Engine builds bundle browser assets (Chart.js, D3, Mermaid, marked, DOMPurify) and synchronize localized builds via `scripts/vendor-engine.mjs`.

## Automation & Workflows

| Workflow | Trigger | Description |
| --- | --- | --- |
| **CI** (`ci.yml`) | Pull Requests & Pushes | Tests on Node.js 24 & 26, verifies dependencies, runs detection benchmarks and browser tests, and runs CLI analysis. |
| **CodeQL** (`codeql.yml`) | Pull Requests & Pushes | Automated security scanning and static code analysis. |
| **Dependabot** (`dependabot.yml`) | Weekly & Immediate | Grouped minor/patch PRs, immediate security update PRs. |
| **Release** (`release.yml`) | Tagged release `v*` | Builds VSIX, attaches release artifacts, and publishes to the Visual Studio Marketplace. |
