Key Features:
=============

✓ Pre-compiled JavaScript (no build needed)
✓ Ready-to-run Docker images
✓ Zero external dependencies (except Node.js in container)
✓ Persistent data volumes (uploads/output)
✓ Production-grade logging
✓ Health checks enabled
✓ Resource limits configured
✓ 4-layer documentation (Setup → Deploy → Reference → Features)

Quick Start (3 steps):
====================

1. Install + Configure:
   bash install.sh
   nano .env

2. Start:
   docker-compose -f docker-compose-prod.yml up -d

3. Access:
   http://localhost:3000

File Size Reference:
===================

dist/                  ~80-100 MB
docs/                  ~0.5 MB
docker-compose*.yml    ~5 KB
Total package:         ~80-100 MB (compressed ~20-30 MB)

Usage Scenarios:
===============

Development:
  docker-compose up -d              # Uses Dockerfile (builds from src)

Production:
  docker-compose -f docker-compose-prod.yml up -d
                                    # Uses Dockerfile_production (dist/)

Customization:
  - Edit docker-compose-prod.yml for resource limits
  - Edit .env for API keys / ports
  - Mount custom volumes for data persistence
