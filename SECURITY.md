# Security Policy

## Supported versions

Security fixes are provided for the latest released version of this project.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues.

Report them privately by using GitHub's "Report a vulnerability" button on the Security tab of this repository:
https://github.com/masahiroid/codes-doctor-vscode/security/advisories/new

Please include:

- A description of the issue and its impact
- Steps to reproduce, or a proof of concept
- The affected version and your environment

## What to expect

- We acknowledge a report within 14 days.
- We assess the report, keep you informed of progress, and aim to release a fix for confirmed vulnerabilities within 60 days.
- After a fix is released, the vulnerability is described in the release notes, and reporters are credited unless they prefer to remain anonymous.

## Scope

This policy covers the source code in this repository. Vulnerabilities in third-party dependencies should also be reported to those projects.
